📘 Mode d'emploi du kit

Tout le site est piloté par des fichiers texte à ouvrir avec le Bloc-notes. Trois niveaux : le menu, les rubriques, les blocs. Il fonctionne sur n'importe quel hébergement web, sans PHP.

Organisation

menu.txt                              ← 1. réglages du site + liste des rubriques
logo/logo.png                         ← logo du site (facultatif)
rubriques/
  Liste MSS collectif/                ← 2. une rubrique = un dossier du nom du menu
    config.txt                        ←    introduction, liste des blocs, documents
    page.html                         ←    contenu libre (texte, tableaux, carte…)
    documents/                        ←    fichiers à télécharger
    MSS du Pays de Quimper/           ← 3. un bloc = un dossier
      config.txt                      ←    ses informations
      logo.png                        ←    son logo

Règles d'écriture (identiques dans tous les fichiers)

• Clé : valeur sur une ligne (ex. Ville : Quimper). Les lignes suivantes sans « : » prolongent le texte.

• [Section] entre crochets, puis un élément par ligne.

• Les lignes commençant par # sont des commentaires ignorés.

• Les noms dans les listes doivent être exactement ceux des dossiers (espaces, majuscules). En cas d'erreur, le site affiche un encadré rouge qui indique le dossier introuvable.

• Noms de dossiers et de fichiers sans accents ni caractères spéciaux (é → e, ô → o, ’ → ', « » à éviter) : c'est plus sûr sur tous les hébergeurs et sous Windows/Mac. Le nom affiché garde ses accents : il se règle dans le config.txt, avec Titre : … pour une rubrique et Nom : … pour un bloc.

1. Le menu : menu.txt

Titre : Kit collectif MSS BZH
Sous-titre : Maisons Sport-Santé
Message d'accueil : Retrouvez ici…
Couleur : #0f766e

[Menu]
Procédure Habilitation & extension MSS
Liste MSS collectif
Partenaires

L'ordre des lignes donne l'ordre du menu. Chaque ligne correspond à un dossier de rubriques/.

2. Une rubrique : rubriques/<Nom>/config.txt

Introduction : Les MSS membres du collectif.
Titre des blocs : Nos MSS

[Blocs]
MSS du Pays de Quimper
MSS Exemple Hôpital

[Documents]
documents/cahier-des-charges.pdf
Modèle de convention | documents/Modèles/convention.docx
https://www.exemple.fr/guide

• page.html : chaque rubrique a sa page, affichée automatiquement sous l'introduction. On y met du texte mis en forme (intertitres, étapes, tableaux), des images ou une carte. Pour intégrer une carte uMap ou une vidéo, collez son code <iframe> dans la page (exemple dans Liste MSS collectif/page.html).
• [Documents] : un fichier par ligne. Libellé | chemin pour choisir le texte affiché. Un sous-dossier (ex. documents/Modèles/) crée un groupe. Les liens web sont acceptés.

Ajouter un filtre personnalisé

Dans le config.txt d'une rubrique, la ligne Filtres : Type d'offre crée un filtre à partir du champ « Type d'offre » des fiches. Dans chaque fiche, écrivez par exemple Type d'offre : APA ou Type d'offre : Sport Santé, APA. La valeur s'affiche aussi en badge violet. Plusieurs filtres sont possibles, séparés par des virgules.

La rubrique « Identification structures Sport Santé » contient les 267 structures relevées le 17/11/2026 sur l'annuaire Bretagne Sport Santé. Les activités « Forme Santé » sont classées Sport Santé, les activités « Maladies chroniques » APA. Chaque fiche contient la ligne Logo : logo.png : déposez simplement un fichier logo.png dans le dossier de la structure pour afficher son logo.

Classer les documents par catégories

Dans la section [Documents], une ligne Catégorie : Nom crée une sous-catégorie. Les documents listés en dessous lui appartiennent. Une catégorie sans document s'affiche quand même, avec la mention « Aucun document pour le moment ». Exemple (rubrique « Documents modèles ») :

[Documents]
Catégorie : Conventions
Convention type MSS / club | documents/Conventions/convention-club.docx

Catégorie : Capsules vidéos
Présentation d'une MSS | https://www.youtube.com/watch?v=...

Les liens YouTube, Vimeo ou Dailymotion s'affichent avec l'icône 🎬.

3. Un bloc : rubriques/<Rubrique>/<Bloc>/config.txt

Nom : MSS du Pays de Quimper
Statut juridique : Association loi 1901
Département : 29 - Finistère
Ville : Quimper
Adresse : 1 rue …
Contact : Prénom Nom
Site : www.mss.fr
Description : Accueil, bilan, orientation…
Horaires : du lundi au vendredi
Document : plaquette.pdf

• Le logo se dépose dans le dossier du bloc sous le nom logo.png (ou logo.jpg, logo.svg, logo.webp). Sans logo, l'initiale s'affiche.
• Toute ligne supplémentaire (ex. « Horaires ») s'affiche sur la fiche.
• Pour un financement, la ligne Émetteur : ARS Bretagne affiche l'émetteur en badge et ajoute un filtre « Tous émetteurs » dans la rubrique.
• Tous les blocs alimentent la recherche. Les filtres Statut juridique et Département se créent à partir des valeurs saisies : écrivez-les toujours de la même façon (ex. « 29 - Finistère »).

Générer le PDF

Sur la page d'accueil, le bouton 📄 Générer le kit en format PDF rassemble le kit dans un document : couverture, sommaire cliquable, puis une section par rubrique. Une fenêtre permet de choisir les rubriques et le contenu (textes, fiches, liste des documents).

À l'étape suivante, choisissez « Enregistrer au format PDF » comme imprimante. Les cartes intégrées (uMap) sont remplacées par leur lien.

Joindre les documents : les fichiers PDF et les images déposés dans les dossiers documents du kit sont rassemblés dans un second fichier, « … - annexes.pdf », téléchargé automatiquement. Chaque document y est précédé d'une page « Annexe n° ». Les documents qui sont de simples liens vers d'autres sites ne peuvent pas être joints : ils restent cités avec leur adresse.

Le livret d'accueil

La rubrique Livret d'accueil affiche un aperçu du livret et le bouton 📘 Générer le livret d'accueil (également présent sur la page d'accueil du kit) : couverture avec le logo du collectif, puis 8 pages A4 numérotées.

Logo de la couverture : déposez logo.png (ou .jpg, .svg) dans le dossier rubriques/Livret d'accueil. À défaut, le logo du site (dossier logo) est utilisé.

Textes de la couverture : lignes Titre du livret, Sous-titre du livret et Mention du livret du config.txt.

Contenu des pages : dans page.html, chaque bloc <section class="livret-page" data-titre="…"> correspond à une page A4. Les pages qui ont un data-titre figurent dans le sommaire, dont les numéros sont calculés automatiquement. Le tableau des financements se remplit à partir des fiches de la rubrique Financements. Gardez des textes courts : une page ne peut pas dépasser une feuille A4.

Les éléments visuels du livret (frise, barres, niveaux, cercles, tableaux) peuvent servir dans n'importe quelle page.html, comme dans la rubrique « Présentation du rôle des MSS ».

Filtres : au moment de générer le livret, choisissez un département et/ou un statut juridique. Le livret ne garde alors que les référents de ce département, les MSS correspondantes et les financements locaux.

Contenus automatiques : le livret reprend les fiches du kit. Financements (avec le lien du champ Site), Formations, modèles de la rubrique « Documents modèles », MSS du collectif, et toutes les fiches qui ont un champ Type de contact (ARS, Délégation départementale ARS, DRAJES, SDJES, Référent collectif, Collectif MSS). Pour changer un référent ou l'adresse du collectif, modifiez la fiche correspondante dans « Contacts » ou « Partenaires ».

Le flash « Dernières informations »

Dans menu.txt, la section [Dernières informations] alimente l'encadré de la page d'accueil. Une ligne par information : Libellé | lien | date | courte description. Le lien peut être une adresse internet, un fichier du kit (chemin depuis la racine) ou une rubrique (#/r/...). Section vide = encadré masqué. Un lien YouTube s'affiche en miniature cliquable en haut de l'encadré.

Champs particuliers

Carte des MSS (rubrique « Liste MSS collectif ») : la ligne Carte : 12 | 45,3 | 60,1 d'une fiche MSS place le numéro 12 sur l'image de la carte, à 45,3 % de la largeur et 60,1 % de la hauteur. Les filtres de la rubrique (statut juridique, département) masquent aussi les numéros sur la carte. Pour une nouvelle carte, remplacez carte/carte-mss-bretagne.jpg et ajustez les lignes Carte.

Financements : le champ Type de financement (Subvention, Appel à projets, Fondation) sert de filtre. La ligne Livret : non retire une fiche du livret d'accueil sans la retirer du kit. La liste des mutuelles est un tableau de page.html.

Outils : une fiche par outil, avec Type d'outil (filtre), Public, Description et Site. N'utilisez pas « et » dans une valeur de filtre (il sépare deux valeurs) : écrivez « Évaluation & suivi ».

Filtres en haut : la ligne Filtres en haut : oui dans le config.txt d'une rubrique place la barre de filtres en début de page. Dans « Liste MSS collectif », elle se place automatiquement au-dessus de la carte et filtre à la fois la carte et la liste.

Sous la liste des fiches : dans un page.html, un contenu placé dans <div class="apres-fiches">…</div> s'affiche sous les fiches au lieu d'au-dessus (exemple : les vidéos de la rubrique Outils).

Recherche : elle porte sur les fiches, le contenu des pages et les libellés des documents. Le filtre « Catégorie » reprend automatiquement les valeurs des champs déclarés en Filtres dans chaque rubrique.

Bon à savoir

• Le site se consulte depuis son adresse web. Pour le tester sur l'ordinateur, double-cliquez sur Lancer-en-local-Windows.bat (ou Lancer-en-local-Mac.command sur Mac) au lieu d'ouvrir index.html. Laissez la fenêtre ouverte pendant l'utilisation.

• Enregistrez les fichiers texte en UTF-8 (choix par défaut du Bloc-notes de Windows 10 et 11).

• Après une modification, rechargez la page (F5). Si rien ne change, faites Ctrl+F5.

• À ne pas toucher : index.html, mode-emploi.html, les lanceurs et le dossier assets.
