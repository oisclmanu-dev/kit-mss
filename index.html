Pour ouvrir le kit sur cet ordinateur

Ouvert par un double-clic sur index.html, le navigateur l'empêche de lire ses fichiers de configuration. Utilisez le lanceur fourni dans le dossier du kit.

🪟WindowsDouble-cliquez sur « Lancer-en-local-Windows.bat ». Laissez la fenêtre noire ouverte pendant l'utilisation.
🍏MacDouble-cliquez sur « Lancer-en-local-Mac.command » (la première fois : clic droit › Ouvrir).
🌐En ligneSur GitHub Pages ou tout hébergement web, le kit fonctionne directement à son adresse.
